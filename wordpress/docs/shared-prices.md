# Shared prices (#208)

Price records own Abo amounts, shares, work, persons, stable calculator keys and the existing membership type. The share price has one settings field. Published records supply both consumers after a guarded initial adoption; the reader preserves zero and rejects an invalid catalog as a whole.

Existing website values stay in use while `bioco_pricing_enabled` is absent. The existing public `/abos` comparison is literal native Text content, so catalog activation alone would leave it stale. The settings screen deliberately offers no activation checkbox.

`wp bioco price-layouts` previews two missing native Divi library starters. `--apply --user=<administrator>` creates only missing library entries. Existing authored layouts, page content and Theme Builder assignments are preserved. The starters use ordinary native Section, Row, Column, Text, Heading and Button modules, native record loops and shared-price dynamic fields. The marked empty branch requires the shared `Bioco_Native_Loop_Empty` adapter.

The native calculator controller updates amount modules and the saved signup button's query parameters. It retains the button's other query parameters, hash and label. A deleted optional module is allowed. Each calculator instance has independent state. The public runtime adds data only; editor, REST and AJAX renders receive no controller config or asset.

Before activation, the release owner must:

- Export the saved table/calculator bodies, price/settings state and applicable library layouts privately.
- Compare all current Abo amounts, share price, shares, work and calculator keys; resolve any divergence before adopting records.
- Preserve the confirmed handoff keys `halb-1-person`, `standard-2-3-personen`, `doppel-4-6-personen` and backend types `halb`, `standard`, `doppel`. `kein` remains shares-only.
- Adopt both native layouts with a body comparison guard, then enable the catalog. Preserve surrounding authored sections and keep a tested restore plan.
- Verify the native price type picker, add a temporary unpublished tier, save/reopen and remove it. Verify native labels, buttons, order, widths and mobile appearance, zero share price, all totals, no-Abo CTA behavior and membership handoff without submitting a live registration.

The parser/browser tests cover storage, bindings, generated block payloads and arithmetic. Their local native DOM adapter replaces Divi rendering/query transport; those checks do not establish native UI persistence or staging/production parity.
